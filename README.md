# Maple Grove Realty CRM

Front-end prototype of a residential real estate lead capture form and Kanban-style CRM pipeline with client-side persistence.

## Problem

Brokerages need a lightweight way to intake leads, score them, and track progression from first contact through closing—without standing up a full backend for early demos.

## Approach

Built a zero-build vanilla JS app with a validated lead form (auto-scoring), CRM dashboard with pipeline stages (New → Contacted → Showing → Offer → Closed), filterable lead board, stat summary, and detail drawer for notes and stage updates. All data persists in `localStorage` with a reset-to-demo option restoring 10 sample leads.

## Results

- End-to-end lead-to-pipeline workflow in a single static site
- Automatic lead scoring on intake
- Kanban pipeline with stage management and notes
- Fully fictional, de-identified sample data—no real contacts or brokerages

## Tech stack

HTML, CSS, vanilla JavaScript, Google Fonts (Inter), localStorage

## How to run

1. Clone or download this repository.
2. Open `index.html` in any modern browser (double-click works).

No install, build step, or server required.
